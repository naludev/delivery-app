**Insta Tragos** is a web platform designed to offer a drink delivery service, allowing users to order alcoholic beverages from the comfort of their homes.  
> 🧠 This project was developed as part of my portfolio, showcasing my skills in **full-stack development**.

---

## 📝 Description

Insta Tragos is built with a **frontend** and a **backend**, each crafted using modern technologies to ensure a smooth user experience and a solid backend infrastructure.

---

## 🎯 Objectives

The main goal of this project is to demonstrate my proficiency in **full-stack development**, including:

- 🔗 Seamless integration between frontend and backend  
- ☁️ Application deployment in production environments  
- ✅ Best practices and design patterns in web development  

---

## 🖥️ Frontend

Built with **React** for its component-based architecture, making the code modular and reusable.  
**Vite** is used as the build tool for fast and efficient bundling.  
**Tailwind CSS** powers the responsive and visually appealing UI.  
**TypeScript** ensures type safety and better code quality.  
**Redux Thunk** manages complex state interactions, especially async operations like API calls.

- 🧩 **Component-Based Architecture** – Scalable and reusable React components  
- 🧠 **State Management** – Centralized state with Redux Thunk  
- 📱 **Responsive Design** – Optimized for desktop and mobile  
- 🛡️ **Type Safety** – TypeScript for early error detection and consistent data structures  

---

## ⚙️ Backend

The backend is built with **Node.js** and **Express**, using **TypeScript** for better maintainability.  
**MongoDB** handles data storage, managing products and orders efficiently.  
The backend supports full **CRUD operations** for products, filters, and orders, providing real-time data.  
**JWT tokens** are implemented for secure user authentication and authorization.

- 🔁 **RESTful API** – Well-structured endpoints for all CRUD operations  
- 🔐 **Authentication** – JWT-based secure user sessions  
- 💾 **Data Persistence** – MongoDB stores products, users, and orders  
- 📈 **Scalability** – Backend designed to handle increased traffic and data load  

---

## 🚀 Deployment

Both frontend and backend are deployed on **[Render](https://render.com/)** – a cloud platform offering reliable and scalable environments.  
Render automates deployment, enabling continuous delivery and easy scaling.  
The database is hosted on **MongoDB Cloud**, ensuring secure and highly available data storage.
